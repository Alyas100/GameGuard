# Frontend Setup

This project uses Expo with Expo Router. Make sure to see the 'Backend repo' of this project too and run it later as backend node.js server.

## Requirements

- Node.js
- npm
- Expo Go application on a phone or an iOS/Android simulator

## Install

```bash
cd frontend
npm install
npm install expo
```

-make sure use command prompt terminal or powershell if in window for the frontend project folder and dont use wsl for it.

## Run the app

```bash
npm expo start
```

## Open on a platform

```bash
npm run ios
npm run android
npm run web
```

## Notes

- If the app fails to load, stop Metro and run `npm start` again.
